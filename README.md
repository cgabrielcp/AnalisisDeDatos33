# Flujo Comun de Git

1. Traer los cambios
   ```bash
   git fetch

   git pull origin main 

2. Estado actual del repositorio local
   ```bash
   git status

3. Agregar los cambios a capa staggin
    ```bash
   git add .

4. Generar el Commit
    ```bash
   git commit -m "Mi primer commit en github"

5. Empujar los cambios
    ```bash
   git push origin main
